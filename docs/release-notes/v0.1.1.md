**asus-ec-sensors-plus 0.1.1: optional bank switching, so the sensors stop going N/A.**

On the TUF GAMING X870-PRO WIFI7 W NEO the BIOS firmware often leaves the
embedded controller (EC) on another register bank for minutes at a time.
In 0.1.0 the sensors showed N/A during those periods. 0.1.1 adds an
optional fix.

### New: `bank_switch=1` (off by default)
For each poll the driver switches the EC's bank register (`0xFF`) to 0,
reads the sensors, and writes the original value back, while holding the
firmware's ACPI lock. This is what the kernel's own `asus-ec-sensors`
driver and LibreHardwareMonitor always do. **No other register is ever
written.** Without the option the driver stays strictly read-only, as in
0.1.0.

Turn it on:
```
sudo cp /usr/share/doc/asus-ec-sensors-plus-dkms/examples/asus-ec-sensors-plus.conf /etc/modprobe.d/
sudo modprobe -r asus_ec_sensors && sudo modprobe asus_ec_sensors
cat /sys/module/asus_ec_sensors/parameters/bank_switch     # Y = on
```

### Tested (BIOS 1805, Ryzen 7 7800X3D)
| Check | Result |
|---|---|
| Values present | 310 of 310 polls over 19 minutes (no N/A) |
| Bank put back after each poll | yes |
| CPU Package vs. k10temp Tctl | within 0-4 °C |
| Fans / PWM | unaffected |
| Kernel log | clean |

### Install (Arch)
```
sudo pacman -U asus-ec-sensors-plus-dkms-0.1.1-1-any.pkg.tar.zst
sudo modprobe -r asus_ec_sensors; sudo modprobe asus_ec_sensors
sensors 'asusec-*'
```
