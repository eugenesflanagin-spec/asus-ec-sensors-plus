**First release: ASUS EC sensors for the TUF GAMING X870-PRO WIFI7 W NEO on Linux.**

This is the Linux kernel's `asus-ec-sensors` driver with this board added,
packaged for DKMS. After installing, `sensors` shows a new `asusec-isa-000a`
block with:

| Sensor | Source | Checked against |
|---|---|---|
| CPU Package | EC `0x31` | k10temp Tctl (within 1-2 °C) |
| CPU | EC `0x30` | moves with Tctl, ~10 °C lower |
| Motherboard | EC `0x32` | Super I/O SYSTIN (equal) |
| VRM | EC `0x33` | plausible 39-42 °C at idle (no other Linux source) |
| CPU_Opt fan | EC `0xB0` | follows CPU fan duty; not a copy of any other fan |

**Read-only:** on this board the module never writes to the embedded
controller.

**Please read before using:** the board's firmware often keeps the EC busy on
another register bank (about half the time in testing; once for more than
25 minutes in a row).
During those periods the sensors show **N/A**. Fine for watching temperatures;
**do not use these readings for fan control**.

### Install (Arch)
```
sudo pacman -U asus-ec-sensors-plus-dkms-0.1.0-1-any.pkg.tar.zst
sudo modprobe asus_ec_sensors
sensors 'asusec-*'
```
Other distributions: see the README, section "Install on other distributions".
